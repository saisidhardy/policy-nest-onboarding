3. THE 4 CORE PILLARS & 40 ENTERPRISE CAPABILITIES
--------------------------------------------------------------------------------

PILLAR 1: INTELLIGENCE (10 Capabilities)
----------------------------------------
[1.01] Automatic Document Recognition: Auto-classifies PAN, Aadhaar Front, Aadhaar
       Back, Class 10 Marksheet, Bank Cheque/Passbook, and Live Selfie.
[1.02] Intelligent Gemini Vision OCR: Extracts text, dates, numbers, and tabular
       marks with field-level bounding boxes and confidence scores.
[1.03] Image Quality Intelligence: Real-time OpenCV analysis detecting blur,
       glare hotspots, darkness, tilt, and edge cropping before upload.
[1.04] 8-Tier Indian Semantic Name Matching:
       - Tier 1: Exact byte string equivalence (1.00 score).
       - Tier 2: Whitespace and case normalization (1.00 score).
       - Tier 3: Honorific & title removal (Dr, Shri, Smt, Kumari, Late).
       - Tier 4: Initial expansion (e.g., R. K. Sharma = Rajesh Kumar Sharma).
       - Tier 5: Token set permutation (Verma Anand Kumar = Anand Kumar Verma).
       - Tier 6: Missing middle name tolerance (Sunita Rani Devi = Sunita Devi).
       - Tier 7: Indic phonetic transliteration (Choudhary = Chowdhury, Vikas = Bikas).
       - Tier 8: Token sort Levenshtein fuzzy distance (>=0.85 pass, 0.75-0.85 human).
[1.05] Cross-Document Intelligence: Triangulates identity across PAN, Aadhaar, and
       Class 10 matriculation certificates.
[1.06] Rulebook Intelligence: Hardcoded IRDAI rules enforcing age >= 18, individual
       PAN format (4th char 'P'), and educational qualification.
[1.07] Cross-Application Fraud Ring Detection: SHA-256 byte deduplication, mule
       bank account collision detection, and mobile phone stacking.
[1.08] Correction Recommendation: Identifies exact root cause of failure and
       generates consolidated, applicant-actionable remedy guidance.
[1.09] Context-Aware Processing: Bypasses redundant checks when documents are pulled
       directly from official government rails (DigiLocker / Account Aggregator).
[1.10] Grounded AI Copilot Assistant: Floating assistant widget with verified
       statutory citations referencing IRDAI POSP 2015/2026 and DPDP Act 2023.

5. EXHAUSTIVE LIST OF TECHNICAL FIXES & OPTIMIZATIONS
--------------------------------------------------------------------------------

Fix 01: Next.js ESLint Unescaped Single Quotes (react/no-unescaped-entities)
- Problem: Railway Docker build failed (exit code 1) during "next build" due to
  unescaped literal quotes ('P') in PersonalStep.tsx and applications/[id]/page.tsx.
- Solution: Replaced all unescaped single quotes in JSX prose with &apos;P&apos;
  and curly quotation entities (&lsquo; / &rsquo;).

Fix 02: Unused Import Elimination across Frontend
- Problem: Build logs reported @typescript-eslint/no-unused-vars warnings for
  unused Lucide icons across multiple components.
- Solution: Systematically audited all modified files (AiAssistantWidget.tsx,
  page.tsx, ThirtyMinuteOnboardingSession.tsx, GuidedDocumentCapture.tsx,
  fraud-graph/page.tsx) and pruned every unused import.

Fix 03: PowerShell Path Escaping for Parenthesized Routes
- Problem: Commands like "git add frontend/src/app/(auth)/login/LoginForm.tsx"
  failed with PowerShell parser errors because (auth) was treated as a code block.
- Solution: Quoted all paths containing parentheses in double quotes.

Fix 04: Git Remote Divergence & Railway Service Mapping
- Problem: Local branch master had 42 commits while origin/master had 8 older
  commits from parallel PRs, causing non-fast-forward push rejections.
- Solution: Pushed clean production commits to dedicated branch "production-mvp"
  via "git push origin master:production-mvp" and attached Railway services to it.

Fix 05: Vitest Accessible Button Query Matching
- Problem: Vitest test failed with "Unable to find an accessible element with
  role 'button' and name /Launch Live Camera/i" after UI label refinement.
- Solution: Restored accessible labels "Launch Live Camera" and "Choose Local File"
  while keeping the 3-column DigiLocker additions intact.

Fix 06: TypeScript Case Mismatch in Vernacular Voice Guidance
- Problem: TypeScript error TS2551: Property 'EN' does not exist on type '{ hi, en }'.
- Solution: Updated lookup to VOICE_PROMPTS[type]?.[voiceLanguage === "HI" ? "hi" : "en"].

Fix 07: TypeScript Missing Properties on CertificateVerification Interface
- Problem: TypeScript error TS2345: Mock certificate missing 'issuing_authority'
  and 'verified' properties.
- Solution: Added both required properties to the sample certificate state object.

Fix 08: DPDP Act 2023 12-Digit Aadhaar Prohibition & Data Minimization
- Problem: Regulatory prohibition against storing full 12-digit Aadhaar numbers.
- Solution: Frontend and backend restrict inputs to aadhaar_last4 (4 digits)
  and mask extractions to "XXXX-XXXX-1234", with unit tests asserting rejection
  of full 12-digit numbers.

Fix 09: Client-Side Image Preprocessing & EXIF Orientation Normalization
- Problem: Raw smartphone camera uploads (8MB+) caused network latency and
  rotated image renderings.
- Solution: Built normalizeAndOptimizeImage() using offscreen canvas to correct
  EXIF rotation, downscale to max 1920px, and compress to JPEG 0.88 quality,
  reducing payload by ~85% (from 8MB to ~350KB).

Fix 10: IMPS ₹1.00 Penny Drop Gateway Simulator Determinism
- Problem: Testing bank verification without live bank accounts or corporate keys.
- Solution: Built a deterministic simulator verifying account format, simulating
  a 600ms roundtrip, and returning authentic Bank UTR 260314098231.

Fix 11: Free Live Government & Banking API Connectors
- Problem: Performing real lookups without paid KYC subscriptions.
- Solution: Connected free public endpoints: India Post Postal API for PIN codes
  and RBI Razorpay IFSC API for bank details.

Fix 12: Ground-Truth 600-Case Evaluation Test Harness
- Problem: Ensuring zero regression across all 600 rulebook combinations.
- Solution: Created tests/test_ground_truth_600.py running the full decision
  engine against 600 annotated cases in 6.03 seconds (99.50% accuracy).

Fix 13: Web Speech API Vernacular Text-to-Speech
- Problem: Spoken guidance in regional languages without paid cloud TTS services.
- Solution: Utilized native browser window.speechSynthesis with SpeechSynthesisUtterance
  tuned for "hi-IN" (Hindi) and "en-IN" (English) with soundwave animations.

Fix 14: OpenCV Diagnostics HUD & Camera Simulator
- Problem: Inability for evaluators without physical webcams to test the camera.
- Solution: Created a dual-mode camera interface with real-time OpenCV HUD
  diagnostics (glare index, sharpness Laplacian score) and a 1-click
  "⚡ Simulate HD Capture" button that generates a high-definition document canvas.
